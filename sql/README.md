# DB 설정

이 저장소에는 마이그레이션 도구가 없습니다. 아래 SQL 파일을 **순서대로 한 번씩** 실행하면 됩니다.
두 파일 모두 여러 번 실행해도 안전합니다 (중복 생성·중복 등록되지 않습니다).

| 파일 | 하는 일 | 안 하면 |
| --- | --- | --- |
| `001_quote_requests.sql` | 견적 문의 접수 테이블 생성 | 홈페이지 견적 폼이 접수되지 않음 |
| `002_seed_projects.sql` | 시공사례 18건 등록 | 시공사례가 비어 있음 |

## 실행 방법

### 방법 1 — DB 제공업체의 SQL 편집기 (가장 간단)

Neon, Supabase, Vercel Postgres 모두 웹 SQL 편집기를 제공합니다.
파일 내용을 그대로 복사해 붙여넣고 실행하세요. 설치할 것이 없습니다.

### 방법 2 — 로컬에서 psql

```bash
export DATABASE_URL="여기에 연결 문자열"
pnpm db:setup
```

`DATABASE_URL`은 Vercel 프로젝트 → Settings → Environment Variables 에 있습니다.

## 실행 후

관리자(`/admin`)에서 두 가지를 확인하세요.

1. **사이트 설정 → 시공사례 노출**을 켭니다. 그래야 홈에 시공사례 섹션이 나옵니다.
2. **시공사례**에서 각 건의 **위치 · 연도 · 소요기간**을 채웁니다.
   이 값들은 실제 정보를 몰라 비워 두었습니다. 공장 담당자가 업체를 고를 때
   가장 많이 보는 항목이므로 채워 두는 편이 좋습니다.

접수된 견적 문의는 **관리자 → 견적 문의**에서 확인합니다.

## 검증 내역

두 파일은 빈 PostgreSQL 16에 실제로 실행해 확인했습니다.

- `001` 실행 후 `quote_requests` 테이블과 인덱스 2개 생성, 재실행 시 오류 없음
- `002` 실행 후 `INSERT 0 18`, 재실행 시 `INSERT 0 0` (중복 없음)
- 앱을 이 DB에 붙여 시공사례 18건이 6개 공종 필터와 함께 정상 표시되는 것,
  견적 폼 제출이 `quote_requests`에 저장되는 것을 브라우저로 확인
